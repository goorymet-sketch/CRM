# Digital Reach CRM

A Python-based CRM for managing companies, leads, sales activities, and follow-ups.

## Initial scope

- Company and contact records
- Lead pipeline and status tracking
- Sales activities and follow-up dates
- Search and filtering
- Future WhatsApp integration (after the core CRM is working)

## Planned stack

- Python 3
- FastAPI
- SQLite for the initial database
- SQLAlchemy for database access
- Jinja2/HTML templates for a simple web interface

## Development approach

The first version will prioritize a small, working CRM over complex automation:

1. Create the application skeleton and configuration.
2. Add database models for companies, contacts, leads, and activities.
3. Add lead management pages and basic search.
4. Add follow-up tracking.
5. Consider WhatsApp integration only after the core workflow is tested.

## Status

Project setup in progress. No WhatsApp messages are sent by this application at this stage.
